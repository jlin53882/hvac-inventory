# 🧊 振佳空調庫存管理系統（hvac-inventory）

家豪的庫存管理系統 — **Variant 1（廠牌分頁卡片版）** 正式版
冷凍空調維修業專用：庫存管理 + 兩階段出庫 + 整組套件 + 每月盤點 + 行事曆派工 + 登入權限 + 照片記錄

---

| 功能 | 說明 |
|------|------|
| 🔍 搜尋 | 名稱 / 編號 / 廠牌 / 備註 即時搜尋 |

| 🔧 整組套件 | 定義套件組成材料，一鍵組裝（扣材料）/拆解（還原） |
| 📅 行事曆派工 | 月行事曆 + 當日派工時間軸 + 防衝突 + 服務項目/人員顏色 + 匯出工程日報表 |
| 📷 品項照片 | 上傳照片自動壓縮，卡片顯示縮圖、可點擊放大 |
| 🔑 帳號登入 | 登入/登出、三種角色（管理員/使用者/檢視者）權限控管 |
| 🔑 個人改密碼 | 隨時改密碼（⚙️ 設定中心）；6 個月未改進站提醒 |
| 📦 單位動態清單 | 4 個 modal 單位欄統一動態下拉（UI 新增即全站同步）；設定中心管理（新增/停用/排序/歷史打錯值收編） |

| 📊 即時統計 | 頂部顯示總品項、廠牌數、缺貨數 |
| 📜 異動紀錄 | 每次加減都有紀錄，可追溯 |

## 🚀 啟動方式

**第一次使用：**
1. 雙擊 `setup.bat`（建立環境 + 匯入資料）
2. 雙擊 `start.bat` 啟動系統

**之後每次使用：**
- 雙擊 `start.bat` → 瀏覽器打開 `http://127.0.0.1:8000`

> 🔑 **預設帳號：`admin / admin123`**（測試帳號）——正式使用請登入後從 topbar「改密碼」更換

### 📱 手機使用（同 Wi-Fi）
- 找電腦 IP（cmd 輸入 `ipconfig` 看 IPv4）
- 手機瀏覽器打開 `http://電腦IP:8000`

### 🌐 外網使用（固定網址）
- 雙擊 `外網啟動.bat` → 取得固定網址 **https://node.tail13203e.ts.net**
- **網址固定不變**：重啟外網後手機不需重新登入（cookie 同 domain 保持）
- 外網使用者**不需安裝任何軟體**，瀏覽器直接開網址即可
- 備援方案：`外網啟動-cloudflared.bat`（網址每次啟動會變，需重新登入）

### 🛡️ 健康監控（自動復原）
系統內建監控（`scripts/monitor.ps1` + 工作排程器）：
- 每 10 分鐘檢查本機 server 與外網網址
- server 掛掉 → 自動重啟；外網掛掉 → 自動重建
- 異常連續 2 次 → 自動推播 Discord 通知
- 安裝：`scripts/install-monitor.bat`（需系統管理員）

## 🔌 API 一覽（精簡）

| Method | Path | 說明 |
|--------|------|------|
| GET | `/health` | 健康檢查（監控用） |
| GET | `/api/items?brand=X&search=Y&location=Z` | 查詢品項 |
| POST | `/api/items` | 新增品項 |
| PATCH | `/api/items/{id}` | 修改品項 |
| POST | `/api/items/{id}/adjust` | 加減庫存 `{delta: ±N}` |
| POST | `/api/auth/login` | 登入（錯誤 5 次鎖 15 分鐘） |
| PUT | `/api/auth/password` | 個人改密碼 |
| GET | `/api/export` | 匯出 Excel |
| GET | `/api/appointments?date=` | 行事曆派工 |
| GET | `/api/appointments/export?date=` | 匯出工程日報表 |

> 全 API 需登入（viewer 對寫入端點 403）。完整清單見 `專案架構.md` §4。
