# 🧊 庫存管理系統

家豪的庫存管理系統 — **Variant 1（廠牌分頁卡片版）** 正式版

## ✨ 功能

| 功能 | 說明 |
|------|------|
| 🔍 搜尋 | 名稱 / 編號 / 廠牌 / 備註 即時搜尋 |
| 🏷️ 廠牌分頁 | 橫向滑動 tab，一鍵切換廠牌 |
| 📍 位置分組 | 依倉庫位置自動分組顯示 |
| ➕➖ 庫存調整 | 點 +/− 或點數字直接輸入，批次儲存 |
| ➕ 新增品項 | 彈窗表單，支援廠牌/編號/數量/單位/位置/備註 |
| ✏️ 編輯品項 | 點品項可改位置/備註/名稱/廠牌/低庫存警示 |
| 📤 領出準備 | 兩階段出庫：先領出準備（庫存不扣），真正出去才扣 |
| 🚚 出庫紀錄 | 幾月幾日、什麼東西、去哪裡（客戶/案場/工地） |
| 📋 每月盤點 | 25 日提醒 + 逐項輸入實際數量 + 自動算盤盈/盤虧 |
| 🔧 整組套件 | 定義套件組成材料，一鍵組裝（扣材料）/拆解（還原） |
| ⬇️ 匯出 Excel | 一鍵匯出完整報表（庫存明細 + 異動紀錄含去向 + 廠牌統計） |
| 📊 即時統計 | 頂部顯示總品項、廠牌數、缺貨數 |
| 📜 異動紀錄 | 每次加減都有紀錄，可追溯 |
| 🔑 帳號登入 | 登入／登出、三種角色（管理員/使用者/檢視者）權限控管 |
| 🔑 個人改密碼 | 隨時改密碼（含檢視者）；6 個月未改進站貼心提醒 |
| 📷 品項照片 | 上傳照片自動壓縮，卡片／已領出列表顯示縮圖 |
| 🛡️ 安全防護 | 防帳號列舉、防超賣負庫存、防跨站請求、圖片像素上限 |

## 📱 頁籤導覽（底部）

| 頁籤 | 功能 |
|------|------|
| 📦 庫存 | 查料、+/−、領出、出庫、編輯 |
| 📤 準備中 | 已領出未出庫的清單（可確認出庫 / 退回） |
| 🚚 出庫紀錄 | 所有出庫流向（時間/品項/數量/去向） |
| 📋 盤點 | 每月 25 日盤點、歷史差異 |
| 🔧 整組 | 套件定義、組裝/拆解 |

## 🚀 啟動方式

**第一次使用：**
1. 雙擊 `setup.bat`（建立環境 + 匯入資料）
2. 雙擊 `start.bat` 啟動系統

**之後每次使用：**
- 雙擊 `start.bat`
- 瀏覽器打開 `http://127.0.0.1:8000`

> 🔑 **預設帳號：`admin / admin123`**（測試帳號）——正式使用請登入後從 topbar「改密碼」更換

**手機使用（同一 Wi-Fi）：**
- 找電腦的 IP（cmd 輸入 `ipconfig`，看 IPv4 位址）
- 手機瀏覽器打開 `http://電腦IP:8000`

```

```

## 🔌 API 一覽

| Method | Path | 說明 |
|--------|------|------|
| GET | `/api/items?brand=X&search=Y&location=Z` | 查詢品項 |
| POST | `/api/items` | 新增品項 |
| PATCH | `/api/items/{id}` | 修改品項 |
| POST | `/api/items/{id}/adjust` | 加減庫存 `{delta: ±N}` |
| GET | `/api/movements` | 異動紀錄 |
| GET | `/api/stats` | 統計 |
| GET | `/api/export` | 匯出 Excel |
| POST | `/api/import` | 批次匯入（逐筆驗證，任一筆錯整批拒絕） |
| POST | `/api/auth/login` | 登入（錯誤 5 次鎖 15 分鐘） |
| PUT | `/api/auth/password` | 個人改密碼（清其他裝置 session） |
| POST | `/api/auth/password-ack` | 密碼過期提醒：按「繼續使用」重置 180 天 |

> **保留 API（未接前端）**（G4，2026-08-11）：以下端點目前前端未使用，供外部整合或未來功能，請勿誤刪：
> `/api/locations`（位置清單）、`/api/movements`（異動紀錄）、`GET /api/stocktakes`（盤點紀錄）、`/api/import`（批次匯入，無 UI）、`/api/stocks/{id}`（PATCH/DELETE）、`/api/items/{id}/stocks`（新增位置）。全 API 需登入，viewer 對寫入端點一律 403。
