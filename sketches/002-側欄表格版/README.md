# Variant: 側欄表格版（桌面/管理用）

## Design stance
桌面管理用的高密度工具——左側廠牌清單（含數量），右側完整資料表格，每列都有狀態燈號與 +/− 快速調整。

## Key choices
- Layout: 固定側欄 220px + 主內容表格（狀態/廠牌/編號/名稱/位置/數量/備註）
- Typography: 表格 13px，欄位對齊工整
- Color: 深藍主色，狀態燈號（綠=充足 / 橘=偏低 / 紅=缺貨）
- Interaction: 廠牌側欄切換、位置下拉篩選、搜尋、列內 +/− 、匯出 Excel

## Trade-offs
- Strong at: 資訊密度高、一次看全部、管理/盤點效率高、低庫存警示
- Weak at: 手機上表格過窄、需要桌面螢幕

## Best for
- 辦公室管理、盤點、老闆查看整體庫存狀況
