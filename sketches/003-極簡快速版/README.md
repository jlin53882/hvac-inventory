# Variant: 極簡快速版（現場速查/加減）

## Design stance
極簡快速——一個大搜尋框 + 廠牌 chips + 純列表，沒有任何多餘裝飾，專注「找得到、加得快」。

## Key choices
- Layout: 頂部巨型搜尋 + 掃描按鈕 + 廠牌 chips（可換行）+ 極簡列表
- Typography: 黑白灰階為主，品名 15px 粗體
- Color: 黑白極簡，只有 + − 用紅綠點綴
- Interaction: 搜尋即時過濾、chips 切換廠牌、大顆 +/− 按鈕、浮動儲存按鈕（帶變更數量 badge）

## Trade-offs
- Strong at: 最快找到品項、最少干擾、學習成本最低
- Weak at: 缺少狀態燈號/備註顯示、無位置篩選、資訊最少

## Best for
- 現場快速查料、緊急找料、不熟悉電腦的使用者
