## 一、角色總覽

| 角色 | 說明 |
|---|---|
| 🛡️ **管理員（admin）** | 擁有系統**全部權限**（含使用者管理）；唯一可操作權限頁的角色。**系統至少須保留 1 位啟用管理員**（保護底線） |
| 👤 **使用者（user）** | 可使用**全部庫存功能**（品項/出庫/盤點/整組/報表/照片/行事曆）；**無法管理帳號**、不可自行改密碼（由管理員重設） |
| 🔧 **工程師（tech）** | **行事曆可寫**（新增/編輯/刪除派工）；其他功能**僅能檢視**（2026-08-13 Sarah：藍政達） |
| 👀 **檢視者（viewer）** | **唯讀**：可看全部庫存資料、待領出/已領出清單、匯出 Excel；**所有寫入一律 403** |

**權限模型（2026-08-13 RBAC）**：角色 = 預設模板（上表矩陣）；**個人開關**可在權限頁覆蓋（如開放某檢視者的品項編輯權限）。覆蓋以個人為單位、立即生效、不需重新登入。

## 三、強制規則（不可被個人覆蓋）

| 規則 | 說明 |
|---|---|
| `view` 不可關閉 | 瀏覽為基底權限，所有角色一律可看（R2 相關：匯出/統計等可個別關閉） |
| `user-mgmt` 僅管理員 | 非 admin 角色看不到此開關（權限頁自動鎖定）；admin 恆為開啟 |
| `change-own-password` 對 admin 恆開 | 管理員必定可自行改密碼；非 admin 可由管理員個別開放 |
| `svc-type-mgmt` 非 admin 不可開 | 服務項目管理僅限管理員 |
| 不能修改自己的權限 | 任何帳號不能改自己的權限、不能停用／刪除自己（權限頁對自己鎖定） |
| 唯一管理員固定最大權限 | 系統只剩 1 位啟用 admin 時，其全部權限強制開啟（防互覆蓋後鎖死） |
| 保護底線 | 任何操作後系統必須仍有 ≥1 位啟用中且持有 `user-mgmt` 的帳號，否則拒絕該操作 |

## 四、稽核紀錄

所有帳號操作（新增／改權限／改角色／啟停／刪除／重設密碼）寫入 `user_audit_log`（誰在何時動了誰），管理員可查（`GET /api/users/audit`）。帳號刪除後稽核軌跡保留（target 欄位清空但不滅證）。
