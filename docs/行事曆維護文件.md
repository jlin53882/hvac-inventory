# 行事曆派工 維護文件（含 API 說明）

> 最後更新：2026-08-13
> 適用：hvac-inventory 系統 📅 行事曆派工功能

## 1. 功能總覽

行事曆派工（bottom-nav 第 1 頁 📅，2026-08-13 起為登入預設頁）：月行事曆 + 當日派工明細（時間軸）+ 新增/編輯派工（防衝突）+ 設定（服務項目 / 人員與顏色）+ 匯出工程日報表。

- 後端檔案：`app/routes/appointments.py`、`app/services/report.py`
- 資料表：`appointments`、`appointment_assignees`、`service_types`（種子：id 1/2/5/6 active＝保養/維修/施工/場勘；3/4 安裝/配管停用保留歷史）
- `users.color`：人員顏色（行事曆顯示用）
- 前端：`static/js/render/calendar.js`、`static/css/style.css`（.cal-*）
- 月曆格派工標籤顯示「時間 [服務] 客戶」（2026-08-13 Sarah 指定；原只顯示時間+人員）

## 2. API 文件

### 行程（appointments）

| Method | 路徑 | 權限 | 說明 |
|---|---|---|---|
| GET | `/api/appointments?year=2026&month=8` | 登入 | 月曆資料（該月全部行程） |
| GET | `/api/appointments?date=2026-08-12` | 登入 | 當日行程清單 |
| POST | `/api/appointments` | 登入（viewer 除外） | 新增行程；同人同時段 → **409 衝突**；記錄 `created_by`（登入者） |
| PUT | `/api/appointments/{id}` | 登入（viewer 除外） | 編輯（衝突檢查排除自己）；`created_by` 保留原值 |
| DELETE | `/api/appointments/{id}` | 登入（viewer 除外） | 刪除行程 |
| GET | `/api/appointments/export?date=2026-08-12` | 登入 | 匯出工程日報表 xlsx（範本填值法） |

**POST/PUT body**：
```json
{
  "client_name": "陳先生 (B棟 3F)",   // 必填
  "address": "新北市板橋區…",          // 選填
  "service_type_id": 2,               // 選填（1=保養 2=維修 5=施工 6=場勘；3/4 已停用）
  "date": "2026-08-12",
  "start_time": "09:00",
  "end_time": "09:00",                // 2026-08-13 起前端只填開始時間，end 自動 = start（後端允許相等）
  "note": "備註",                      // 選填
  "user_ids": [1, 2]                  // 必填（至少一位負責人）
}
```

**回傳範例**（GET/POST/PUT）：
```json
{
  "id": 5, "client_name": "陳先生", "address": "…", "service_type_id": 2,
  "service_name": "維修", "date": "2026-08-12",
  "start_time": "09:00", "end_time": "11:00", "note": "…",
  "created_by": 1, "created_by_name": "管理員", "created_at": "2026-08-11 23:59:53",
  "user_ids": [1], "assignees": [{"id": 1, "name": "管理員", "color": "#1a73e8"}]
}
```
- `created_at` 為 **UTC**（前端轉本地顯示）
- `created_by_name`：新增者（UI 明細卡頂部橫條顯示；**不匯出到 Excel**）

### 服務項目（service_types，字典）

| Method | 路徑 | 權限 | 說明 |
|---|---|---|---|
| GET | `/api/service-types` | 登入 | 服務項目清單（含停用） |
| POST | `/api/service-types` | admin | 新增（同名 → 400） |
| PUT | `/api/service-types/{id}` | admin | 更新名稱/排序/啟用 |
| DELETE | `/api/service-types/{id}` | admin | 停用（is_active=0，不真刪） |

> 日報表勾選欄（D/F/H/J = 保養/維修/施工/場勘、✓ 在 E/G/I/K）**固定對應 service_types id 1/2/5/6**（2026-08-13 Sarah：安裝/配管 → 施工/場勘）——種子不可刪除/改 id，新增的服務項目不會進勾選欄（匯出時地點欄附註）。

### 其他

| Method | 路徑 | 權限 | 說明 |
|---|---|---|---|
| GET | `/api/assignable-users` | 登入 | 可指派人員（啟用中且非 viewer），含 role/color |

## 3. 匯出工程日報表規則（§10 範本填值法）

- 方式：`report.py` 以 openpyxl 載入 `app/assets/工程日誌範本.xlsx` → 填值 → BytesIO 回傳（**版面零寫死**，改格式只改範本檔）
- sheet 名 = `mmdd`；B 欄寬固定 **20**；縮放 130 分頁預覽
- **A2「工程師：」不帶名稱**（2026-08-12 家豪指定：由工程師手寫；API 層 assignees 仍保留）
- 每筆行程 → 區塊（最多 5 筆）：A=項次、B=時間（2026-08-13 起只填開始時間）、C=客戶、勾選欄 ✓、備註區第 1 列 `地址：xxx`（有填才顯示）、第 2 列備註（不加前綴）
- 未使用區塊：A/B/C/勾選/備註全部清空（避免殘留範本佔位）
- 公式注入防護：`_safe()`（= + - @ 開頭加撇號）

## 4. 權限

- viewer：可看行事曆/字典/匯出，寫入（新增/編輯/刪除/字典管理）403
- user：可新增/編輯/刪除行程；字典管理需 admin
- admin：全部

## 5. 常見維護操作

- **改日報表格式**：編輯 `app/assets/工程日誌範本.xlsx`（B 欄寬 20 由程式固定，其餘以範本為準）
- **加服務項目**：設定 → 服務項目 → 新增（不會進日報表勾選欄）
- **換人員顏色**：設定 → 人員與顏色 → 點色塊
- **重啟外網**：`外網啟動.bat`（cloudflared quick tunnel，網址每次會變——登入狀態會因此失效屬預期行為）
