# Excel 匯出欄寬與明細呈現

## 欄寬規則

- 所有 XLSX 工作表都由 `app/services/excel_layout.py` 的 `auto_fit_columns()` 依表頭與資料內容估算每欄寬度，不沿用匯出程式寫死的欄寬。
- 中文全形字元以兩個寬度單位估算；多行內容以最長一行估算；水平合併儲存格的內容依合併範圍分攤需求寬度。
- 欄寬最小為 8、最大為 Excel 支援的 255。超出上限的文字受 Excel 格式限制，應使用換行或調整內容；openpyxl 不會計算公式，公式結果以保守寬度估算。
- 新增 XLSX 匯出時，完成所有資料、樣式與合併儲存格後呼叫共用欄寬 helper，並在對應匯出測試中驗證標題、長資料與合併範圍。

## 匯出標題與分頁命名

- 庫存類匯出的可見標題採「報表類型－內容」格式，工作表分頁使用相同名稱；為保留分頁順序，總覽／統計分頁可加 01／06 順序前綴。
- 報價單 Excel 的第一列為合併標題「報價單」；工程日報範本標題與下載名稱使用「工程日報表」。
- 工程零用金收據欄統一稱為「發票／收據號碼」。
- 一般零用金與工程零用金的可見主標題依維護者決定保留既有文字，後續改欄名或版面時不可順帶改動這兩個標題。

## 零用金明細項次

- 項次代表原始收支紀錄，不代表展開後的 Excel 明細列。
- 一筆支出有多個細項時，所有細項列共用同一項次，項次欄與日期、金額、科目欄一樣跨列合併；下一筆收支紀錄只增加 1。
- 回歸測試應檢查多細項項次值相同且合併，後續項次不因細項數量偏移。

## 匯出範圍

- 共用活頁簿匯出：單一庫存、整組庫存、已領出。
- 範本或獨立產生器：一般／工程零用金、工程日報表、報價單。
- 相關回歸測試：`tests/test_export.py`、`tests/test_petty_cash.py`、`tests/test_petty_cash_excel_rendering.py`、`tests/test_work_progress_ui_regressions.py`、`tests/test_main.py`。
